# hanko.css

Component-layer CSS for the hanko mark. Imported from `styles/main.css` as
`layer(components)` so it outranks the base layer and Tailwind's inline
overlay utilities without `!important`.

## Role
Display a looping animation that runs during the page load sequence. ^b20f9a

## Why plain CSS, not Tailwind

The SVG is fetched from Sanity at build time and inlined by the
`inlineSvgFromUrl` filter. Tailwind's scanner only reads source templates, so
utility classes carried by the fetched markup (`fill-current` etc.) are
generated by coincidence at best. Safari's stricter `@layer` handling exposed
this: paths fell back to default black fill on a black background. The fix
scopes plain CSS to `.hanko-mount` — a class we own in
[hanko.njk](../../views/atoms/hanko/hanko.njk) — and targets `svg` / `path`
elements so it holds regardless of what Sanity ships.

## Rules

| Selector | Does |
| --- | --- |
| `.hanko-mount` | Fallback `color` (`--color-secondary-700`) when caller passes no `text-*` class |
| `.hanko-mount > svg` | `display:block`, `width:100%`, `height:auto`, `max-height:100%` — width-driven, height-clampable |
| `.hanko-mount svg, … path` | `fill: currentColor` |
| `[data-preloader]` | Timing tokens: `--hanko-pulse-cycle` 1.75s, `--hanko-enter-duration` 0.75s, `--hanko-enter-delay` 1s, `--hanko-settle-duration` 0.4s |
| `[data-preloader] .hanko-mount :is(#data,#ink,#input,#output)` | Resting opacity + infinite `hanko-loading-pulse` |
| `… #data / #ink / #output / #input` | `animation-delay` staggered by 25% of cycle → clockwise chase |
| `… #frame` | Static `opacity: 0.75` |
| `[data-preloader][data-preloader-state="exit"] …` | `animation: none`, `opacity: 1`, eased by `--hanko-settle-duration` |

`@keyframes hanko-loading-pulse`: hump 0→40→60% (0.35 → 1 → 0.35), trough
held to 100%. Asymmetric rest keeps only two paths lit at once and breaks
antiphase pairing.

## Contracts

- **Path IDs** `#data`, `#ink`, `#input`, `#output`, `#frame` must exist in the
  Sanity SVG. Renaming them in Sanity silently kills the pulse.
- **`data-preloader`** is set by
  [home-landing.njk](../../views/organisms/header/home/home-landing.njk);
  other hanko instances (header, hero, footer) stay static.
- **Exit flip**: [Preloader.js](../../js/preloader/Preloader.js) sets
  `data-preloader-state="exit"` (attribute/value in
  [constants.js](../../js/preloader/constants.js)) and never removes it.
  `constants.js` also mirrors `--hanko-settle-duration` as the JS timeout
  fallback — change both together.
- **Reduced motion**: `styles/utilities/reduced-motion.css` forces
  `animation: none`, so users see the resting opacity, not the pulse. The
  exit `transition` still runs.
