Every table in this section is generated from `js/choreography/config/` and
`js/choreography/tokens/` when the site builds. To change a value, change the
config file.

- **[Events](events/)**: every event name on the bus.
- **[Selectors](selectors/)**: section ids and the `data-*-el` hooks.
- **[Presets](presets/)**: each section's timing and transform values.
- **[Profiles](profiles/)**: which variant runs at each breakpoint, and under
  reduced motion.
- **[Tokens](tokens/)**: the primitive values everything else derives from.
